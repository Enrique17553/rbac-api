# 🛡️ Enterprise RBAC API

API REST para gerenciamento de autenticação e controle de acesso baseado em papéis (RBAC).

---

## 📌 Sobre o Projeto

Esta aplicação fornece um sistema completo de autorização granular. Ela permite que administradores criem permissões dinâmicas, atribuam essas permissões a papéis (*roles*) e vinculem esses papéis a usuários, garantindo que cada endpoint seja acessado apenas por perfis autorizados.

### 🛠️ Tecnologias Utilizadas
* **Linguagem/Framework:** [Ex: Node.js / TypeScript / NestJS]
* **Banco de Dados:** PostgreSQL
* **Cache & Sessão:** Redis
* **Autenticação:** JWT (Access & Refresh Tokens)
* **ORM:** [Ex: Prisma / TypeORM]
* **Containers:** Docker & Docker Compose
